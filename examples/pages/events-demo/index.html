📡 Multi-Subscriber Events

The new API exposes events through service.on(event, listener), which returns an unsubscribe function — and service.off(event, listener). Unlike the old single callback properties, many independent subscribers can listen to the same event without clobbering each other. Add a few subscribers below, then navigate the grid with a controller (or click a card) and watch every subscriber fire.
