This page demonstrates the gamepad-index="true" attribute for controlling which elements are focusable!

When useGamepadIndex: true, only elements with gamepad-index="true" are included in navigation.

💡 Navigation Tips:
  • When useGamepadIndex: false → All normally focusable elements are included
  • When useGamepadIndex: true → Only elements with gamepad-index="true" are included
  • Provides precise control over gamepad navigation scope
  • Perfect for complex layouts with selective focus
