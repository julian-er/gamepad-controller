🪟 Custom Events — WinUI / Host Mode

Some hosts (WinUI/WebView2, kiosk shells, native wrappers) read the controller themselves and have no navigator.getGamepads(). For those, initCustomEventGamepad() ignores the native Gamepad API and instead listens for DOM CustomEvents the host dispatches: hubgamepadconnected, hubgamepadstatechanged, hubgamepaddisconnected — each carrying detail.gamepad (a standard-shaped gamepad snapshot).

There's no real controller here — the buttons below simulate the host by dispatching those events. Navigation, selection, and button callbacks all respond exactly as they would from a physical pad.
