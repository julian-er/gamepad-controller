Quick Integration

Integrate into your framework in under 10 lines of code.

navigation.ts 
import { gamepadService } from 'gamepad-controller';

// Initialize navigation engine
const ctrl = gamepadService({ deadzone: 0.15 });
ctrl.init();

// Set current screen scope
ctrl.setActiveScope('dashboard', { trapFocus: true });

// Listen for actions or button presses
ctrl.on('action', (e) => console.log('Gamepad Action:', e));

Essential API Reference

The four core methods you need to build any gamepad interface.

Method Parameters Description
init(options?) options?: GamepadOptions Initializes the 60Hz gamepad loop and registers browser event listeners.
setActiveScope(id, opts?) id: string, opts?: ScopeOpts Pushes a focus scope (e.g. modal or menu) to restrict navigation.
on(event, callback) 'action' | 'beforeaction', fn Subscribes to directional navigation or button actions with cancellation support.
destroy() none Stops polling, cleans up listeners, and releases all focus references.
