# Stitch source archive

Project: Gamepad Controller Documentation System (`17072487755286859910`). Retrieved through the Stitch MCP on 2026-09-15. Hosted code and screenshots downloaded with `curl -f -L`.

`screens.json` retains titles, IDs, and hosted URLs. The `.html` extension reflects Stitch's code field; token exports contain raw SCSS, JSON, or Markdown. There are 5 UI HTML screens, 3 image-only screens, and 5 text/code exports. Design system asset stubs correspond to the two records in `design-systems.json`.

The source exports contain Tailwind/CDN references; they are reference files only, outside the public and compiled application. The application is rewritten in React and Sass. Marketing statistics in the designs are not treated as verified library capabilities.

Screenshots were subsequently downloaded with Google's `=s0` suffix to preserve original resolution. Named copies of the JSON token exports and `DESIGN-export.md` are included for convenience. The application fonts were downloaded from the Google Fonts stylesheet referenced by the designs; their OFL licenses are preserved alongside the self-hosted font files.
